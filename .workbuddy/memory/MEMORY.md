# 项目长期记忆 — 「我是我 V2.0」

## 项目定位
本地优先 Electron 桌面应用（Win x64 便携交付，不做安装程序）。核心闭环：了解现状 → 分析主要矛盾 → 确认目标 → 制定行动 → 记录进展 → 调整下一步。不做自动复盘系统；复盘页 = 纯手写绝对隐私笔记。

## 导航终版
首页 · 现状 · 目标 · 行动 · 复盘 · 我是我 · 见证成长 + 底部设置。除「我是我」「见证成长」外均为两字名。排序逻辑：高频在前（复盘每次可能都用），低频在后（我是我=个人感悟、见证成长=自动统计）。首页布局按用户截图：侧边栏只放品牌+导航+设置（无搜索框/无对话入口）；输入框上方一行 = 新对话/历史对话按钮 + 右侧模型状态。

## 关键决策（用户确认）
- 行动页两区域：解决主要矛盾的行动步骤 + 用户需保持的习惯（服务长期任务）。
- 草案确认交互：AI 给出矛盾 + 关联行动草案，用户点击确认写入；确认弹窗内矛盾与行动均可编辑。行动必须关联矛盾。
- 成长轨迹：时间线板块，节点记录解决了的矛盾，增强成就感，设计要求高。
- 发送透明：无感知被动展示本次回答参考的数据来源概要，不需要用户操作。
- 依据链：只在 AI 分析矛盾时说明用了哪些感悟推导出行动方案，不在行动板块显示。
- 不做：全局搜索页、侧边栏搜索框、习惯频率字段、EPUB 解析、自动复盘系统、行动与目标结构化关联、LangChain/LangGraph、复盘笔记任何 AI 开放通道、逐条隐私标记。
- 复盘页：绝对隐私（reflections 表，contextBuilder 架构级排除，无任何跨界功能）；系统提示词告知 AI 模块存在但不可读。
- 记忆机制「启动即消化」：聊天时零后台任务（watermark 游标），启动时后台静默整合（记忆提取+摘要+档案比对），不阻塞；当前会话上下文 = 最近约 20 条。
- UI 哲学：界面干净，信息宁少勿多，避免分散用户精力导致只想不干。
- 我是我：仅单一感悟流；核心思想引文（毛泽东《矛盾论》主要矛盾论述）固定置顶、样式区分、不可删除；新感悟默认排在其下，可拖拽排序。粘贴文本提炼观点，经用户编辑确认后入库。
- 现状页（原个人档案）：分类标签 = 单一功能 + 两个字（如「交通」「资产」），不写复合标签；预设分类带示范作用，支持自定义分类；AI 默认可检索全部档案。页面名「现状」= 概念模型四要素之一，数据概念称「现状档案」，表名 profileCards 不变。
- AI 信息分类学：已确认事实（档案/感悟/用户汇报的进展）、已采纳计划（矛盾/目标/行动，可参考不当作事实）、AI 推断、待确认问题。行动指南不属于已确认事实。
- AI 行为一致性：内置静态系统提示词（每次请求注入，含矛盾论核心方法论与行为准则）+ 动态上下文（画像/记忆/档案来自数据库，换模型不失魂）+ 测试连接角色自检。
- AI：仅 OpenAI 兼容接口 + 本地 Ollama（默认 http://localhost:11434）。单配置（不做多配置档案）：同 Key 换模型名=仅换模型；换 Key/换地址→模型名清空重选；获取模型列表（/v1/models、/api/tags）。
- 数据导出/清空：感悟与复盘导出 .md，其余 JSON；导入备份=覆盖现有全部数据+二次确认（无自动快照）；清空数据=全部用户数据含 AI 配置，回出厂状态。
- Git：本地 init + commit；远程仓库地址由用户在合适时机提供，构建期间不推送。
- 工作目录：D:\CodeLab\我是我V2.0（勿动旧项目 D:\CodeLab\我是我）。
