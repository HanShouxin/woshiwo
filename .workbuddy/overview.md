## 二、聊天层（Phase 2 主体）

### 会话与消息
- `appendMessage` 自动维护 `seq`（会话内单调递增），这是记忆整合游标的锚点，删消息不回退
- 删除会话时级联删消息与摘要；长期记忆的条数可单独查询（留给 Phase 3 的删除确认弹窗）
- 「＋ 新对话」「历史对话」（弹出式列表，示例会话带「示例」标记）

### 草案协议落地
- 解析器 `src/renderer/src/ai/draft.ts`：识别 ` ```draft ` 块 → 校验 schema → 输出正文 + 草案；坏 JSON / 缺字段一律降级纯文本，**不显示确认入口**
- 一条消息只取第一个草案块（防止模型多吐）
- **5 个测试**覆盖：正常解析、坏 JSON、schema 非法、多块取首个、无块原样

### 草案确认卡片
- 矛盾用大号 textarea 可直接改字；行动逐条可改、可删、可加
- 「确认写入」→ 写当前矛盾 + 关联行动（步骤挂在该矛盾下，习惯进长期习惯区），并把消息标记 `draftState: confirmed`
- 「先不采纳」→ 只收起，不写库

### 示例会话
- 首次运行（无会话时）自动生成一段完整对话：困境 → 现状/目标/差距/主要矛盾/为什么是它 → 草案卡片
- 会话标 `kind: 'sample'`，**草案卡片是只读演示态**（点不了确认），引导语说明「示例里的草案不能直接采纳」
- 并发保护：StrictMode 双执行也只建一份

### 未配置模型时
发送后消息正常入库，下方给一条明确提示（不伪造 AI 回答、不假装在思考）。
