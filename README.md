# 我是我 V2.0

本地优先的个人成长桌面应用。用 AI 对话理清现状，找出当下最该解决的那个主要矛盾，把精力压在能推动局面的一件事上。

> 研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。

## 现在是什么状态

**Phase 0 完成**：工程骨架、七个页面、深浅主题、便携数据目录、单实例锁、IPC 白名单。

**Phase 1 完成**：本地数据层与真实 CRUD —— 11 张表（含独立复盘库）、现状/目标/行动/我是我/复盘/见证成长全部接上真实数据、矛盾生命周期（设定→替换归档→解决→进时间线）、7 个数据层测试。

**尚未接入**：AI 对话、草案确认卡片、记忆整合、备份导入导出（Phase 2–4）。

## 开发

```bash
npm install
npm run dev        # 启动开发窗口（热更新）
npm run test       # 数据层测试（fake-indexeddb）
npm run typecheck  # 类型检查
npm run build      # 生产构建到 out/
npm run dist       # 打包便携版到 release/（Phase 5）
```

环境要求：Node 18+（本项目在 Node 22 上开发）。国内网络下载 Electron 二进制需要镜像，`.npmrc` 已配置。

## 两条不能破的线

1. **数据不出设备。** 所有数据存在本机，只有你配置了远程模型时，对话上下文才会发给你选择的服务商。API Key 只经 `safeStorage` 加密保存在主进程，不进数据库、不进日志、不进备份。
2. **AI 不替你决策。** 主要矛盾、目标、行动只能以草案形式提出，必须你确认后才写入正式记录。
