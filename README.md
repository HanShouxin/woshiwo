# 我是我 · V2.0

[![Release](https://img.shields.io/github/v/release/HanShouxin/woshiwo?label=%E4%B8%8B%E8%BD%BD)](https://github.com/HanShouxin/woshiwo/releases/latest)
[![License](https://img.shields.io/github/license/HanShouxin/woshiwo)](https://github.com/HanShouxin/woshiwo/blob/main/LICENSE)

> 钱塘江上潮信来，今日方知我是我。

一个**本地优先**的个人成长桌面应用。它不做打卡、不做励志、不给你打分，只做一件事：

**帮你找到当前的主要矛盾，然后只解决它。**

核心闭环：了解现状 → 分析主要矛盾 → 确认目标 → 制定行动 → 记录进展 → 调整下一步。

方法论来自毛泽东《矛盾论》：一个复杂过程里同时存在两个以上矛盾时，全力找出它的主要矛盾；捉住了这个主要矛盾，一切问题就迎刃而解。

## 下载与使用

**不需要安装 Node.js，也不需要懂代码。** 这是一个免安装的绿色软件。

### 四步开始

1. **下载**：打开 [Releases](https://github.com/HanShouxin/woshiwo/releases/latest)，在 Assets 里下载 `我是我-v2.0-win-x64.zip`（约 156 MB）
2. **解压**：解压到任意目录。建议放在 `D:\Apps\` 这类普通文件夹，不要放 `C:\Program Files`（那里需要管理员权限写数据）
3. **运行**：进入解压出的 `win-unpacked` 文件夹，双击 **`woshiwo.exe`**
4. **配置模型**：点左下角「设置」→ 填配置名称、模型名、接口地址、API-KEY → **先点「测试连接」**，显示绿色「连接成功」后再保存

配置好后回到首页，先在「现状」里记几条你现在的情况，然后开始对话。

### 支持的模型

| 类型 | 接口地址示例 | 说明 |
|---|---|---|
| OpenAI 兼容 | `https://api.deepseek.com/v1` | DeepSeek、阿里百炼、通义、硅基流动等都兼容 |
| 本地 Ollama | `http://localhost:11434/v1` | 需要本机已运行 Ollama，完全离线，不需要 Key |

模型名必须填服务商文档里给出的准确名称（例如 `deepseek-chat`）。可以保存多套配置（如「百炼」「公司 Ollama」），从「已保存配置」里随时切换。

### 数据在哪里

| 操作 | 怎么做 |
|---|---|
| 数据存放 | 解压目录下的 `win-unpacked\data\` 文件夹 |
| 换电脑 | 把整个 `win-unpacked` 文件夹拷过去，数据一起带走 |
| 备份 | 设置 → 数据与备份 → 导出备份（JSON，不含 API-KEY） |
| 彻底删除 | 先导出备份（如果需要），再删掉整个文件夹 |

所有数据只在本机，不上传任何服务器。API-KEY 用系统级加密单独存放，不进数据库、不进备份。

### 系统要求

- Windows 10 / 11，64 位
- 解压后约 397 MB 磁盘空间
- 使用在线模型需要联网；用 Ollama 可完全离线

### 常见问题

**双击没反应 / 被 Windows 拦截**
这是没有代码签名证书的软件的通病。Windows SmartScreen 会提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。

**提示连接失败**
先确认接口地址末尾带 `/v1`（大多数服务商需要），再确认模型名拼写正确。Ollama 用户请确认本地服务已启动，可以直接在浏览器打开 `http://localhost:11434` 看看有没有输出。

**换电脑后打开是空的**
数据在 `data` 文件夹里，只拷 exe 不拷 `data` 就会是空库。要么整个文件夹一起拷，要么用「导出备份 / 导入备份」。

## 它和别的效率工具有什么不同

| 常见做法 | 这个应用的做法 |
|---|---|
| 列出所有待办，让你自己排优先级 | 一次只聚焦**一个**主要矛盾，其余的明确告诉你"排在后面" |
| AI 直接给你一套计划 | AI 只能提**草案**，矛盾和行动都由你确认后才写入 |
| 用打卡天数衡量成长 | 不统计打卡，只在「见证成长」里记录你**解决过的矛盾** |
| 数据存在云端 | 所有数据在本机，一个文件夹拷走就是全部 |

## 功能

| 页面 | 作用 |
|---|---|
| **首页** | 与 AI 对话。AI 读完你的现状、目标、感悟与记忆后给出分析，末尾附一份可编辑的行动草案 |
| **现状** | 你现在拥有什么、处于什么状态。按分类记卡片，写得越具体 AI 判断越准 |
| **目标** | 短期目标（按优先级排序）与长期目标（并列） |
| **行动** | 左边是当前主要矛盾与行动步骤，右边是你要长期保持的习惯 |
| **复盘** | 纯手写私人笔记。没有 AI、没有分析、没有建议 |
| **我是我** | 感悟流。核心思想引文固定置顶，新感悟排在其下，可拖拽调整顺序 |
| **见证成长** | 解决过的矛盾形成时间线 |

### 几个细节

- **行动草案**：AI 给出矛盾 + 行动（步骤按紧急程度从高到低排列），你在卡片里逐条修改，点确认才写入
- **来源透明**：每条 AI 回复下方有一行「参考：现状 3 · 目标 1」，点开能看到具体引用了哪些条目
- **启动即消化**：下次打开应用时，后台静默把上次对话提炼成长期记忆与会话摘要，不打扰你
- **长期习惯是用户的领地**：AI 草案里的「习惯」只作参考，不会自动写入，必须你自己添加

## 隐私设计

这不是一句宣传语，是架构决定的：

- **数据不出设备**：全部存在本机 IndexedDB，没有任何同步、上传、遥测
- **API Key 不进数据库**：用操作系统级加密（Windows DPAPI / `safeStorage`）单独存放，导出备份时不含密钥
- **复盘绝对隔离**：复盘使用**独立的数据库文件**，AI 的上下文组装在架构层就没有这条通道，系统提示词里也明确告知 AI「该模块存在但你无法读取」
- **远程模型需要你主动选择**：默认支持 OpenAI 兼容接口（DeepSeek、百炼等）与本地 Ollama；用远程模型时上下文会发给你选定的服务商，想彻底离线就切 Ollama

## 技术栈

- **框架**：Electron 45 + React 19 + TypeScript
- **构建**：electron-vite（主进程 / preload / 渲染进程三段构建）
- **本地数据库**：Dexie（IndexedDB），11 张表 + 1 个独立复盘库
- **AI 请求**：全部走主进程，SSE 流式解析，支持中途停止
- **图标**：纯 Node 脚本生成（超采样 4× 抗锯齿 + 手写 PNG/ICO 编码），无第三方图像库

## 开发

```bash
npm install

npm run dev        # 启动开发窗口（热更新）
npm run test       # 数据层 / 备份 / 拖拽逻辑测试（27 项）
npm run typecheck  # 类型检查（主进程 + 渲染进程）
npm run build      # 生产构建到 out/
npm run dist       # 打包便携版到 release/
```

### 配置模型

设置 → AI 模型连接 → 填写配置名称、模型名、接口地址、API-KEY → **先测试连接**，通过后保存。

- 兼容地址示例：`https://api.deepseek.com/v1`、Ollama 本地 `http://localhost:11434/v1`
- 可以保存多套配置（如「百炼」「公司 Ollama」），从「已保存配置」里随时切回
- 密钥只在本机加密保存，界面里点眼睛图标可查看与复制

### 打包

```bash
npm run dist
```

产出 `release/win-unpacked/`，双击 `woshiwo.exe` 即可运行，**免安装**。数据存在程序目录下的 `data/`，把整个文件夹拷到另一台 Windows 机器上就是完整迁移。

重新生成图标：

```bash
node scripts/make-icon.mjs   # 输出 build/icon.png 与 build/icon.ico
```

## 数据管理

设置 → 数据与备份：

- **导出备份**：全量 JSON（不含 API Key）
- **导入备份**：覆盖现有数据，导入前有二次确认
- **导出感悟**：Markdown，核心思想置顶
- **导出复盘**：生成「我是我-复盘笔记」文件夹，每篇一个 txt，文件名即你填的标题（同名自动加序号，标题里的非法字符会自动清理）
- **清空全部数据**：连同 AI 配置与密钥一起清除，回到出厂状态

## 项目结构

```
src/
├── main/           主进程：窗口、AI 代理（SSE 流式）、密钥加密、文件读写
├── preload/        白名单 IPC 桥接
├── renderer/src/
│   ├── ai/         系统提示词、上下文组装、草案解析、启动即消化
│   ├── components/ 页面骨架、可编辑文本、弹窗、草案卡、来源行
│   ├── db/         表结构、仓储函数、备份导出
│   ├── pages/      七个页面
│   └── styles/     设计令牌与布局
├── shared/         主进程与渲染进程共享的类型与常量
tests/              数据层、备份、拖拽重排测试
scripts/            图标生成脚本
```
